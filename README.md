# Isaac Sim VR Teleop (WebXR + WebRTC)

Meta Quest 3などのVR HMD内蔵ブラウザから、Isaac Sim 6.0上の**FANUC CRX-10iA/L**を遠隔操作するプロジェクトです。映像はWebRTCで受け取り、ヘッドセットとコントローラの動きでロボットを動かします。VLA学習用のデータ収集（LeRobot形式）、自分のVRMアバターでシーンに入る没入表示にも対応しています。

## シーン

| 種類 | アセット |
| --- | --- |
| ロボット | `Isaac/Robots/Fanuc/crx10ia_l/crx10ia_l.usd`（FANUC SimReadyと同一。台座上に設置） |
| テーブル | `SimReady/Industrial/Warehouse/Equipment/Stainless_Metal_Table_A03` |
| グリッパ | `Isaac/Robots/Robotiq/2F-85`（指で物体を物理的に挟みます） |
| 掴む対象セット（切替式） | 果物: 赤りんご、バナナ<br>部品: ソケット（7/8in）、アイドラープーリー、リレー、燃料インジェクター<br>工具: プラスドライバー、トルクスドライバー、エクステンションバー、ソケット（3/4in）<br>電装品: ヒューズ（大・中・小）<br>ボルト・ナット: M20 / M16のボルトとナット（Isaac Lab Factoryアセット）<br>小部品: ベアリング（大・小）、バルブリフター、テープ<br>小物: ゴルフボール、キャンドル、ルービックキューブ、テープロール<br>（いずれも把持方向の幅が2F-85の開口85 mm以内） |
| 常設 | トレイ（SimReady Gray_Crate_A14、60×40×15 cm、固定）、コーヒーカップ、桃缶、キューブ |
| 鏡 | テーブル奥の姿見（表示はDR / UIで切替） |
| 環境 | `Isaac/Environments/Grid/default_environment.usd` + Dome/Distant/Sphereライト |
| カメラ | Operator / Front / Top / Wrist（フランジ）/ Dataset（学習データ用） |
| 操作者アバター | `assets/avatars/avatar.vrm`または環境変数`TELEOP_AVATAR`で指定したVRM（任意。起動時にUSDへ変換して配置） |

- **掴む対象セット**: VRメニューの「セット」、2Dパネルのデータ収集欄で切り替えます。選んだセットだけがテーブルに出て、タスクの対象やランダム化も選んだセットだけになります。自前のモデルは`assets/props/<セット>/`に置いてシーンを再生成すると追加できます（[assets/props/README.md](assets/props/README.md)）。
- **把持アシスト**（既定ON）: 小さい部品・丸い部品・平たい部品は、指が当たって止まった時点でグリッパに固定して一緒に動かします（開けば離します）。2Dパネルの設定でOFFにできます。
- **グリッパの種類**: `C:\isaacsim\python.bat server\build_scene.py --gripper virtual`でシーンを作ると、旧来の吸着式（見た目だけのツール）になります。
- 物体に強く押し付けると腕が止まるようにしてあり、指で押し込んでも物体が弾き飛ばされにくくしています。
- シミュレーションは実時間で進みます。描画fpsが落ちてもアームはスロー再生になりません。

## セットアップと起動

前提: Isaac Sim 6.0.1が`C:\isaacsim`（違う場合は環境変数`ISAACSIM_PATH`）、Node.js 20以上。

```bat
run_server.bat
```

初回は自動で以下を行います（個別に実行しても可）:

1. `server\install_deps.bat` … aiortc / PyJWT / pyarrow / PyNvVideoCodecなどを`server\_deps`にインストール（`C:\isaacsim`は変更しません）
2. `C:\isaacsim\python.bat server\build_scene.py` … シーンUSD生成
3. `webapp`で`npm install && npm run build` … `webapp\dist`はPythonサーバが配信

> 既存の`scene/vr_teleop_scene.usda`がある場合、`run_server.bat`はシーンを再生成しません。グリッパや鏡、追加した小物を反映するには`C:\isaacsim\python.bat server\build_scene.py`を実行してください。

### 主なオプション

| オプション | 内容 |
| --- | --- |
| `--port 8443` | 待ち受けポート |
| `--no-stereo` / `--stereo-size 960 540` | 単眼で起動（既定は立体視） / 立体視の片目の解像度 |
| `--width 1280 --height 720 --fps 30` | モニター表示の解像度とfps |
| `--bitrate 8000000` | 映像のビットレートの基準（1280×720での値） |
| `--video-codec auto\|nvenc\|x264\|vp8` | 映像のエンコーダ。既定のautoはGPUのNVENCでH.264、使えなければCPUのlibx264 |
| `--headless` | ウィンドウなしで起動（ペアリングコードはコンソールに出力） |
| `--no-tls` | HTTPで起動（localhostでの確認用。WebXRにはHTTPSが必要） |
| `--physics-hz 30` | 物理のステップ数/秒。60にすると細かくなる代わりに重くなる |
| `--viewport auto\|on\|off` | Isaac Sim自身のビューポートの描画。既定のautoでは、誰かが映像を受信している間とヘッドレス時は止めます |
| `--avatar FILE` / `--no-avatar` | 使うVRMの指定（環境変数`TELEOP_AVATAR`より優先） / アバターなし |
| `--profile` / `--kit-trace <出力.json>` | 計測用（[AGENTS.md](AGENTS.md)の「計測」） |

データ収集のオプション: `--dataset crx10ial_teleop`（保存名）/ `--dataset-root datasets` / `--record-fps 15` / `--record-size 256 256` / `--codec libsvtav1|libx264` / `--no-record`。

### Questからの接続

1. PCとQuestを同じLANに置き、Windowsファイアウォールで`kit.exe`の受信（TCP 8443とWebRTC用UDP）を許可します。
2. QuestブラウザでIsaac Simの「VR Teleop - Pairing」ウィンドウに表示されたURL（例`https://192.168.x.x:8443/`）を開きます。自己署名証明書の警告は「詳細 → アクセスする」で進みます（WebXRにはHTTPSが必須のため、初回起動時にLAN IPを含む証明書を`server/certs`に自動生成します）。
3. 「接続を要求する」→ Isaac Simのウィンドウに出た**6桁コード**を入力 → 接続 → 「VRを開始」。

ヘッドセットなしでVR表示を確認するときは、URLに`?xremulate`を付けて開くとMeta Quest 3のエミュレータが有効になり、キャンバスの左右に各目の映像が表示されます。

### ペアリングとセッション

- 6桁コードは**Isaac Simのウィンドウにだけ**表示されます。有効期限は120秒で、5回間違えると失効します。
- 同じ端末から再度要求すると、前の要求は新しいコードに置き換わります。
- 接続は既定で8時間有効です。サーバを再起動すると全端末でペアリングし直しになります。
- ペアリングウィンドウの「Revoke」でその端末の接続をすぐに切れます。

## VLA学習データ収集（pi0-FAST / LeRobot）

Web AppとVRパネルの「データ収集」から、タスクを選んで録画できます。データはLeRobot v2.1形式（parquet + AV1動画）で`datasets/`に保存されます。収集されるデータの詳細、成功判定、openpiでの学習設定は[docs/vla_finetuning.md](docs/vla_finetuning.md)を参照してください。

## 操作

**VRコントローラ**（操作する手は設定で左右切替）

| 手 | 入力 | 動作 |
| --- | --- | --- |
| 操作する手 | グリップ長押し | クラッチ: 押している間、コントローラの相対移動/回転をツールに反映 |
| | トリガー | グリッパ閉（離すと開） |
| | A/X・B/Y・ スティック押込 | カメラ切替 ・ ランダム化 ・ ホーム姿勢 |
| 反対の手 | X/A長押し ・Y/B・ スティック上下 ・ スティック押込 | リセット ・ メニュー位置切替 ・ モニター距離（没入表示では歩行） ・ 録画開始/成功で保存 |

- **VRメニュー**: 既定では反対の手のコントローラの上に浮かぶ手元メニュー（リセット/ランダム化/カメラ/グリッパ/ホーム/回転モード/移動倍率/鏡/表示切替/アバター/手の役割/解像度/録画/立体視/左右入替/VR終了）です。操作する手のレイで押します。Y/Bボタンで「手元 → 左下に固定 → 非表示」と切り替えられます。状態表示はモニターの上辺に出ます。レイがメニューに乗っている間はトリガーが固定されるので、ボタンを押してもグリッパは開閉しません。
- **状態バーの警告**: 「操作権なし」「コントローラ入力なし」「右手のコントローラが見えません」が出たら、その理由で入力が効いていません。操作できるのは1台だけですが、操作中の端末の接続が切れたり1秒以上入力が途絶えたりすると、入力を送ってきた端末に自動で移ります（ページ再読み込み直後も操作できます）。2Dパネルの「操作権を取得」でも取れます。
- **操作基準（モニター表示時）**: 「表示カメラ」（既定。見ている映像の向きに合わせ、手を右に動かすと画像上で右、前に出すと画像の奥へ。視点を切り替えると基準も変わる）、「オペレータ視点」（どのカメラを見ていても常にオペレータカメラ基準）、「ロボット」（手を前に出すとロボット正面方向+Xへ）から選べます。2DパネルまたはVRメニューの「操作基準」で切り替えます。
- **VR内の表示**: VRメニューの「表示:」または2Dパネルの「VR内の表示」で切り替えます。
  - **モニター表示**（既定）: 空間に浮かぶ仮想モニターで、選んだカメラ（オペレータ / 正面 / 真上 / リスト）の映像を見ます。モニターはカメラ画角と同じ視野角になるサイズで表示されます。
  - **没入表示**: 自分がIsaac Simのシーンの中に入ります。Isaac Sim内のステレオカメラがHMDの位置と向きに追従し、VRの視界とシミュレーション空間が1対1で対応するので、手を動かした方向に見たままアームが動きます。映像に遅延があっても、頭を回したときに映像が一緒に流れません（新しく見える部分が少し遅れて現れるだけです）。
  - 没入表示では、反対の手のスティックで歩行移動、操作する手のスティック左右で30°ずつ回転、「正面リセット」でテーブルの向かい側（ロボットの正面）に立ち直します。
- **回転モード**: 「水平のみ」（既定。グリッパの傾きを保ったまま鉛直軸まわりにだけ回る。上からつかむ作業向け）、「全軸」、「なし」。
- **手ぶれ補正**: 手を止めているときの細かい揺れを抑えます（速く動かしたときの遅れは小さく保ちます）。強さは2Dパネルで調整できます。
- **立体視（モニター表示）**: 2Dパネルの「ステレオ配信」またはVRメニューの「立体視」で切り替えます（既定はON。`--no-stereo`で単眼から始まります）。VRに入るとQuestが測った目の間隔を自動で反映するので、モニターの距離に関係なく物体が実際の距離に見えます。左右が逆に見えるときは「左右入替」。

**コントロールパネル**（2D/デスクトップでも利用可）: リセット（DRの見た目を戻すオプション付き）、ホーム、グリッパ、TCPジョグ、カメラ選択、テレオペ設定、ドメインランダマイゼーション設定、解像度、映像の計測。

## 操作者アバター（VRM）

VRMファイル（VRM 0.x / 1.0）を指定すると、サーバ起動時にUSDへ自動で変換してシーンに登場させます。指定方法は次のどちらかで、どちらもなければアバターは読み込みません。

- 環境変数`TELEOP_AVATAR`にVRMファイルのパスを設定する（相対パスはプロジェクトのフォルダから）
- `assets/avatars/avatar.vrm`という名前で置く

```bat
set TELEOP_AVATAR=assets\avatars\MyAvatar.vrm
run_server.bat
```

環境変数で指定したファイルが見つからないときは、`avatar.vrm`があっても読み込まずに、ログに警告を出します。起動オプションの`--avatar FILE`は環境変数より優先し、`--no-avatar`はどちらの指定も無視します。

ヘッドセットと両手のコントローラの姿勢から全身の姿勢を計算するので、鏡に自分の姿が映り、Isaac Sim内のカメラからも人として見えます。

- **表示**: 没入表示のときだけ、VRの頭の位置にそのまま立ちます。2Dパネルの「アバターを表示」、VRメニューの「アバター」で切り替えます。
- **大きさ**: 本人の目の高さに合わせて拡大縮小します。腕が短いアバターでは、コントローラに届くように腕を伸ばします。
- **動き**: しゃがむと腰が下がり、首と頭はヘッドセット、手はコントローラの向きに合わせます。指はトリガー（人差し指）とグリップ（中指〜小指）で曲がります。足は床に固定し、体が離れると踏み出します。髪・スカートなどの揺れもの（スプリングボーン）も動きます。表情には対応していません。
- **当たり判定**: 手で物体を押せ、ロボットはアバターに当たると止まります。2Dパネルの「アバターの当たり判定」でON/OFFします（既定ON）。
- **データ収集中**: 既定では録画の準備から終了までアバターを隠します（学習用カメラはオペレータ位置のすぐそばにあるため）。2Dパネルの「録画中はアバターを隠す」で切り替えられます。
- **見た目**: トゥーン（MToon）は近似表示です。輪郭線とリムライトは再現しません。
- **変換**: 起動のたびに確認し、VRMを差し替えたときと初めて使うときだけ変換します（変換結果は`assets/avatars/_converted/`）。

## 没入表示で物を掴む

没入表示では、自分の手（コントローラ）で物体を直接掴めます。グリップボタンを押したとき、手の近く（約6 cm以内）にある物体を掴み、離すと手の速さで放します（投げられます）。ロボットのグリッパが掴んでいる物体も取れます。

- **手の役割**（2Dパネル「没入表示での手」、VRメニュー「手:」）
  - ロボット+掴む（既定）: 操作する手はロボットを操作し、反対の手のグリップで物を掴みます。
  - 両手で掴む: 両手とも物を掴む手になり、ロボットの操作は止まります。
- 掴んでいる物体はVRメニューの状態表示に「左手: ◯◯」のように出ます。
- リセットや対象セットの切り替えをすると手を離します。

## 解像度と画質

2Dパネルの「解像度」で、表示モードごとの配信解像度を実行中に変更できます。VRメニューの「解像度」ボタンは、いま使っているモードの解像度を順に切り替えます。

| モード | 選択肢（既定は太字） |
| --- | --- |
| モニター（単眼） | 960×540 / **1280×720** / 1600×900 / 1920×1080 |
| モニター立体視（片目、左右並びで2倍幅） | 640×360 / **960×540** / 1280×720 / 1600×900 |
| 没入（片目、正方形） | **1024** / 1280 / 1536 / 1792 / 2048 |

同じ欄で次の2つも変えられます。

- **描画（DLSS）**: 性能 / バランス / 画質 / ネイティブ。既定は「性能」（内部では低い解像度で描いて拡大）で、画質を上げるほど重くなります。
- **ビットレート上限**: スライダーで2〜100 Mbps。「自動」にすると解像度に合わせて決めます。実際のビットレートは多くの場合これより低くなります（一定の画質を狙うため）。

解像度を上げるほど描画とエンコードが重くなり、fpsが下がります。参考（RTX 3090、アバターあり）: 没入表示の片目1024で約22 fps、1536で約18 fps、2048で約14 fps。起動時の既定値は`--width/--height`、`--stereo-size`で指定できます。

映像はGPU（NVENC）でH.264にエンコードします。NVIDIAのGPUがない、またはNVENCが使えない環境ではCPUでエンコードします（ログに`NVENC unavailable`）。

## 映像の計測

映像の各段階にかかる時間を、2Dパネルの「映像の計測」とVR内のステータス行（`sim ◯ / 映像 ◯ fps　遅延 ◯ ms`）に表示します。映像を受信している間は、サーバのログ（`teleop.perf`）にも5秒ごとに記録します（Quest側の数値も含む）。

| 項目 | 内容 |
| --- | --- |
| Kit更新 | 物理 + 全カメラの描画 |
| 前処理 / アバター | IK・入力・アバター |
| 画像取得 / 左右の連結 | カメラ画像の取り出しと、左右の目を並べる処理 |
| 頭の姿勢反映 → 配信 | 没入表示で、画像の描画に使った頭の姿勢を反映してから配信するまで |
| エンコード | H.264への圧縮 |
| デコード / 受信バッファ待ち / サーバ配信 → 表示 | ブラウザ側 |
| 頭の動き → 表示 | 没入表示で、頭を動かしてから、その姿勢で描いた画像が表示されるまで |

映像の受信中はIsaac Simのビューポートの描画を止めています（GUIの画面は受信が終わるまで止まって見えます）。常に描画したい場合は`--viewport on`で起動してください。

## ドメインランダマイゼーション

| 項目 | 内容 |
| --- | --- |
| 物体配置 | テーブル上に非重複で再配置 + ランダムyaw |
| 照明 | 強度倍率・色温度・キーライト方向・ドーム回転 |
| 素材/色 | 台座・床の色/粗さ/金属度（SimReadyテーブルは対象外） |
| カメラ揺らぎ | 表示中の固定カメラと学習用Datasetカメラの位置/回転ジッタ |
| 鏡の有無 | 指定確率で鏡を表示/非表示（当たり判定は残る） |
| 物理 | 質量倍率・摩擦係数 |

項目ごとの有効/範囲、「リセット時に実行」、自動実行間隔、シードをWebから設定できます。変更は「リセット + 見た目を戻す」で元に戻せます。
